# Movie-Recommendation-System-
Welcome to the Movie Recommendation System — your personalized movie companion! Discover movies you’ll love based on your preferences. This application uses machine learning techniques and is built with ❤️ using Streamlit.

## 🚀 Features

✅ Smart movie recommendations based on user selection  
✅ Fast and intuitive user interface  
✅ Live deployed and ready to use  
✅ Powered by Content-Based Filtering  
✅ Built using Python, Pandas, and Scikit-learn

## 💻 Run Locally

Follow these steps to run the project on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/movie-recommendation-system.git

# 2. Navigate into the project directory
cd movie-recommendation-system

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the Streamlit app
streamlit run app.py
